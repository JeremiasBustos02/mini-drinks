# 18 — Dirección visual

## Objetivo

Definir una base visual suficiente para diseñar y desarrollar la primera versión de la web sin caer en una estética genérica de ecommerce.

La dirección visual no busca cerrar todavía:

- nombre definitivo;
- logo final;
- packaging final físico;
- sistema completo de piezas de marca.

Sí busca fijar un criterio visual claro para el MVP digital.

---

# Concepto general

La marca debe sentirse:

- fresca;
- juvenil;
- minimalista;
- moderna;
- atractiva;
- con personalidad;
- divertida sin ser infantil;
- visualmente memorable.

No queremos una estética de:

- vinoteca clásica;
- bar premium oscuro;
- ecommerce genérico;
- tienda fría sin identidad.

La referencia aspiracional es una web con criterio visual fuerte, similar al nivel de intención de estudios/diseños como Cloudstudio.

## Definición resumida

> Minimalista en estructura, atrevida en composición.

---

# Sensaciones buscadas

La web debe transmitir:

- “quiero probar eso”;
- “esto está bueno”;
- “se ve distinto”;
- “es un producto para regalar, compartir o pedir ya”;
- “es moderno y fácil”.

No debe transmitir:

- burocracia;
- formalidad excesiva;
- lujo clásico;
- seriedad de vinoteca;
- catálogo aburrido.

---

# Paleta base

## Colores definidos

- `#0D0D0D`
- `#F5F3F0`
- `#FFFFFF`
- `#024018`
- `#A5C7B7`

## Roles sugeridos

### 1. Negro profundo — `#0D0D0D`

Uso:

- texto principal;
- títulos sobre fondo claro;
- íconos;
- contraste;
- fondos puntuales muy oscuros.

Debe aportar presencia y estructura.

### 2. Crema cálido — `#F5F3F0`

Uso:

- fondo principal del sitio;
- grandes superficies;
- bloques de descanso visual.

Este color evita que la web se vea como “blanco genérico” y le da personalidad.

### 3. Blanco — `#FFFFFF`

Uso:

- cards;
- inputs;
- overlays;
- paneles;
- superficies elevadas.

### 4. Verde principal — `#024018`

Uso:

- botones primarios;
- links destacados;
- badges;
- elementos de marca;
- acentos importantes;
- secciones CTA.

Debe ser el color protagonista de acción.

### 5. Verde suave — `#A5C7B7`

Uso:

- fondos secundarios;
- tags;
- destacadores suaves;
- chips;
- pequeños detalles gráficos;
- acentos de apoyo.

## Regla de proporción

No dar el mismo peso a todos los colores.

Distribución conceptual sugerida:

- 60% fondos claros (crema/blanco);
- 25% negro;
- 15% verdes.

---

# Tipografías

## Titulares

**Bowlby One SC**

Uso recomendado:

- H1;
- H2;
- títulos de impacto;
- títulos de secciones;
- títulos de cards destacadas;
- frases cortas.

No usarla para bloques largos ni para subtítulos muy extensos.

La función de Bowlby es aportar personalidad, no resolver toda la legibilidad del sitio.

## Texto funcional y descriptivo

**Roboto**

Uso recomendado:

- párrafos;
- menú;
- botones;
- inputs;
- fichas;
- descripciones;
- precios secundarios;
- labels;
- formularios.

Roboto debe encargarse de la lectura cotidiana.

## Regla de convivencia

Bowlby = impacto.  
Roboto = claridad.

---

# Jerarquía visual

## Títulos

Grandes, visibles y cortos.

Ejemplos de tono:

- TU TRAGO. EN MINI.
- UNO. Y LISTO.
- ARMÁ EL TUYO.
- LOS QUE NO FALLAN.
- ¿UNO O PARA TODOS?

## Textos

Cortos y directos.

Evitar párrafos largos en home.

## Botones

Claramente visibles, con copy amigable.

Ejemplos:

- Ver combos
- Armar el mío
- Me llevo uno
- Ver individuales
- Quiero venderlos
- Consultar eventos

---

# Redondeo

El nivel de redondeo debe ser medio.

No completamente cuadrado.  
No exageradamente bubble.

Sugerencia conceptual:

- cards: medio;
- botones: medio;
- inputs: medio;
- badges/chips: alto.

Debe sentirse amigable pero limpio.

---

# Estilo de CTAs

Los CTA deben sentirse:

- cercanos;
- claros;
- amigables;
- juveniles;
- frescos;
- visibles.

## CTA principal

Sugerencia:

- fondo verde `#024018`;
- texto claro;
- tamaño generoso;
- bordes redondeados;
- presencia fuerte.

## CTA secundario

Sugerencia:

- fondo claro o blanco;
- borde oscuro o verde;
- contraste suficiente;
- menos peso que el principal.

## Copy recomendado

Evitar botones excesivamente fríos como:

- Comprar
- Enviar
- Continuar

Preferir cuando tenga sentido:

- Ver combos
- Armar el mío
- Me llevo uno
- Quiero este
- Ver packs
- Quiero venderlos

---

# Estilo de layout

## Principio

No construir una web hecha solo de grillas repetitivas.

La composición debe combinar:

- bloques amplios;
- ritmo visual;
- cards de distintos tamaños;
- producto grande;
- títulos grandes;
- respiración;
- contraste entre secciones.

## Estructura ideal

- pocas secciones pero bien resueltas;
- mucho espacio negativo;
- imágenes protagonistas;
- contenido escaneable en móvil;
- bloques con personalidad editorial.

---

# Estilo de cards

Las cards deben sentirse modernas y comprables.

Deben priorizar:

- producto visible;
- nombre fuerte;
- precio claro;
- CTA simple;
- aire;
- esquinas redondeadas.

Las cards destacadas pueden variar levemente de tamaño para dar ritmo visual.

---

# Estilo fotográfico y de producto

## Dirección

No usar lenguaje de bar premium clásico.

Evitar:

- madera;
- humo;
- luces cálidas oscuras;
- ambientes de whisky de lujo.

Buscar:

- producto recortado;
- fondos limpios;
- manos;
- composición visual divertida;
- sensación de objeto/regalo;
- unboxing;
- packaging;
- miniaturas y vaso como protagonistas.

## Imágenes recomendadas

- miniaturas aisladas;
- mini combos armados;
- vaso;
- stickers;
- packaging;
- producto en mano;
- grupos de productos.

---

# Lenguaje gráfico

El sistema gráfico puede apoyarse en:

- títulos gigantes;
- stickers visuales;
- pequeños sellos;
- chips;
- etiquetas;
- elementos de repetición relacionados con packaging.

Ejemplos de microelementos:

- “50 ML”
- “MINI”
- “UNO Y LISTO”
- “+18”
- “TOP”
- “NUEVO”

No deben abusarse, pero pueden aportar carácter.

---

# Home: intención visual

La home debe vender rápido.

Debe comunicar:

1. qué es el producto;
2. por qué está bueno;
3. qué puede comprar el usuario;
4. cómo pedir;
5. que también existe opción mayorista.

La primera pantalla debe tener fuerte impacto visual.

---

# Catálogo

El catálogo no debe sentirse como una lista fría.

Debe conservar:

- identidad de marca;
- filtros claros;
- cards limpias;
- sensación de compra impulsiva.

---

# Constructor “Armá tu combo”

Debe ser uno de los espacios más atractivos del sitio.

Sensaciones:

- simple;
- divertido;
- interactivo;
- visual;
- nada técnico.

Debe invitar a explorar sin cansar.

---

# Mobile-first

La experiencia debe estar pensada principalmente para teléfono.

Prioridades:

- títulos claros;
- imágenes grandes;
- botones fáciles de tocar;
- navegación simple;
- resumen visible;
- carrito accesible.

---

# Qué evitar

- estética premium oscura;
- exceso de texto;
- exceso de colores;
- demasiados bordes gruesos;
- demasiada rigidez;
- demasiados efectos visuales;
- apariencia SaaS genérica;
- home que parezca un catálogo aburrido.

---

# Resultado buscado

La web debe verse como una marca con intención.

Si alguien entra desde Instagram, debe sentir:

> esto no es una tienda más; es un producto con identidad.
