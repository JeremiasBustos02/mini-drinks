# 07 — Flujos de usuario

## A — Comprar individual
Instagram → Home/link → Producto → Cantidad → Carrito → Checkout → Entrega/retiro → Pago → Confirmación.

## B — Combo predeterminado
Instagram → Combo → Contenido → Extras → Carrito → Checkout → Pago → Confirmación.

## C — Armar combo
Home → Armá tu combo → Miniatura → Mixer → Vaso → Extras → Precio → Carrito → Checkout → Pago.

## D — Pack personalizado
Packs → Tamaño → Configurar unidades → Revisar → Carrito → Checkout.

## E — Compra como invitado
Carrito → Checkout → Datos → Entrega → Pago → Confirmación → Invitación opcional a crear cuenta.

## F — Usuario registrado
Login → Compra → Checkout simplificado → Pago → Pedido → Puntos/recompensas según reglas.

## G — Canjear código
Cuenta → Canjear → Escanear QR/ingresar código → Validación → Acreditación → Confirmación.

## H — Ruleta
Cuenta → Mis puntos/Ruleta → Ver requisitos → Girar → Premio → Guardar recompensa/cupón.

## I — Mayorista
Home → CTA mayoristas → Página → Formulario/WhatsApp → Contacto → Cotización manual.

## J — Evento
Home → Eventos → Opciones → Solicitud → Contacto → Cotización manual.
